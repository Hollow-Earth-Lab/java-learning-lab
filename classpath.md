Флаг `-cp` в Java означает **classpath**, то есть путь к классам, которые нужны для запуска программы.

---

### 🧠 Что такое classpath?

Classpath — это список директорий и `.jar` файлов, где Java ищет классы (`.class`) и библиотеки, чтобы запустить программу. Без правильного classpath Java просто не найдёт нужные классы.

---

### 📦 Пример использования `-cp`

Допустим, ты скомпилировал `Hello.java` и положил `Hello.class` в папку `bin/`. Тогда запуск будет таким:

```cmd
java -cp bin Hello
```

Это говорит Java: «Ищи классы в папке `bin`, и запусти класс `Hello`».

---

### 🧱 Можно указать несколько путей

```cmd
java -cp "bin;lib/mylib.jar" MainClass
```

- `bin` — твои собственные классы
- `lib/mylib.jar` — сторонняя библиотека
- В Windows пути разделяются `;`, в Linux/macOS — `:`

---

### 🔥 Инженерный стиль

Ты можешь оформить запуск как модульный скрипт:

```cmd
@echo off
set CLASSPATH=bin;lib/*
java -cp %CLASSPATH% MainClass
```

И запускать через `run.bat`, как системный агент.
