Несколько простых задач по программированию на Java для начинающих, которые помогут освоить основы языка. Задачи подобраны так, чтобы охватить ключевые концепции: переменные, условия, циклы, массивы, строки и методы. К каждой задаче прилагается краткое описание и пример решения для одной из них.

---

### 1. Калькулятор двух чисел
**Описание**: Напишите программу, которая запрашивает у пользователя два числа и выполняет основные арифметические операции (сложение, вычитание, умножение, деление). Выведите результаты.

**Подсказка**: Используйте `Scanner` для ввода данных и операторы `+`, `-`, `*`, `/`.

---

### 2. Проверка четности числа
**Описание**: Напишите программу, которая запрашивает у пользователя целое число и определяет, является ли оно четным или нечетным.

**Подсказка**: Используйте оператор `%` для проверки остатка от деления на 2.

---

### 3. Факториал числа
**Описание**: Напишите программу, которая вычисляет факториал введенного пользователем числа. Например, факториал 5 равен `5 * 4 * 3 * 2 * 1 = 120`.

**Подсказка**: Используйте цикл `for` или `while`.

---

### 4. Обратный порядок строки
**Описание**: Напишите программу, которая запрашивает строку у пользователя и выводит её в обратном порядке. Например, для строки `"Привет"` результат: `"тевирП"`.

**Подсказка**: Используйте цикл или методы класса `StringBuilder`.

---

### 5. Сумма элементов массива
**Описание**: Создайте массив целых чисел (можно задать вручную или заполнить случайными числами). Напишите программу, которая находит сумму всех элементов массива.

**Подсказка**: Используйте цикл `for` или `for-each`.

---

### 6. Простое число
**Описание**: Напишите программу, которая проверяет, является ли введенное пользователем число простым (делится только на 1 и на само себя).

**Подсказка**: Используйте цикл для проверки делителей от 2 до корня из числа.

---

### 7. Фибоначчи
**Описание**: Напишите программу, которая выводит первые N чисел последовательности Фибоначчи, где каждое следующее число — сумма двух предыдущих (начинается с 0, 1).

**Подсказка**: Используйте цикл и временные переменные для хранения предыдущих чисел.

---

### Пример решения: Проверка четности числа
```java
import java.util.Scanner;

public class EvenOrOdd {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Введите целое число: ");
        int number = scanner.nextInt();
        
        if (number % 2 == 0) {
            System.out.println(number + " - четное число");
        } else {
            System.out.println(number + " - нечетное число");
        }
        
        scanner.close();
    }
}
```

### Советы для начинающих:
- **Практикуйтесь**: Решайте задачи последовательно, начиная с простых.
- **Используйте IDE**: IntelliJ IDEA или Eclipse упростят написание и отладку кода.
- **Проверяйте ввод**: Добавляйте обработку некорректных данных (например, деление на 0 или неверный ввод).
- **Комментируйте код**: Это поможет понять логику позже.
