Если ты хочешь объявить **глобальную переменную** в Java — то есть доступную во всём классе — вот инженерно корректный способ:

---

## 🧱 Объявление глобальной переменной

```java
public class MyProgram {

    // Глобальная переменная
    static int counter = 0;

    public static void main(String[] args) {
        counter++;
        System.out.println("Счётчик: " + counter);
    }

    public static void incrementCounter() {
        counter++;
    }
}
```

---

## 🔍 Ключевые моменты:

- `static` делает переменную **общей для всех методов класса**
- Без `final` — значит, её можно изменять
- Можно использовать в любом `static` методе, включая `main()`

---

## ✅ Когда использовать:

| Модификатор        | Назначение                          |
|--------------------|--------------------------------------|
| `static`           | Глобальная переменная для класса     |
| `final` + `static` | Глобальная константа                 |
| без `static`       | Переменная экземпляра (нужен `new`)  |
