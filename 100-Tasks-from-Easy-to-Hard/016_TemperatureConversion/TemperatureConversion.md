В задании «16. Конвертация температуры» тебе нужно реализовать **преобразование между температурными шкалами**. Вот инженерная декомпозиция задачи:

---

### 🧱 Цель задачи:
- Получить температуру от пользователя
- Получить тип шкалы (например, Цельсий, Фаренгейт)
- Перевести температуру в другую шкалу
- Вывести результат с пояснением

---

### 🔧 Минимальный алгоритм:
1. Прочитать число — температура
2. Прочитать строку — исходная шкала (`C`, `F`, `K`)
3. Прочитать строку — целевая шкала
4. Выполнить конвертацию по формуле
5. Вывести результат с единицами

---

### 📐 Примеры преобразований:

| Из | В | Формула |
|----|---|---------|
| Цельсий → Фаренгейт | `F = C × 9/5 + 32` |
| Фаренгейт → Цельсий | `C = (F − 32) × 5/9` |
| Цельсий → Кельвин   | `K = C + 273.15` |
| Кельвин → Цельсий   | `C = K − 273.15` |

---

### 🧪 Рекомендации:
- Проверяй корректность ввода (число, допустимые шкалы)
- Используй `if-elif-else` для выбора формулы
- Добавь обработку ошибок (`try-except`)
- Можно оформить как функцию `convert_temperature(value, from_scale, to_scale)`
