Алгоритм перевода из десятичной системы в двоичную:

Берёшь число в десятичной системе.

Делишь его на 2.

Запоминаешь остаток (он будет 0 или 1).

Результат деления снова делишь на 2.

Повторяешь, пока не получишь 0.

Собираешь остатки в обратном порядке — и вуаля, двоичное число.

Пример: переведём 13.

13 ÷ 2 = 6, остаток 1

6 ÷ 2 = 3, остаток 0

3 ÷ 2 = 1, остаток 1

1 ÷ 2 = 0, остаток 1

Читаем остатки снизу вверх: 1101.


Делимое (divisible) — это число, которое делится; 
divider делитель — это число, на которое делят; 
quotient частное — это результат деления.

remainder остаток от деления

В Java для выполнения деления без остатка используется оператор деления /, который возвращает целую часть результата. Если вам нужно проверить, делится ли число нацело, можно использовать оператор остатка %.
