Javadoc это не просто комментарии, это **инструмент инженерной документации**, встроенный прямо в Java. Он превращает твой код в **самодокументируемую систему**, которую можно читать как API-справочник. Давай разберу по слоям:

---

## 🧠 Что такое Javadoc

**Javadoc** — это формат комментариев в Java, который позволяет автоматически генерировать HTML-документацию из исходного кода. Он используется для описания:

- Классов
- Методов
- Переменных
- Параметров и возвращаемых значений

---

## 🔧 Как выглядит Javadoc-комментарий

```java
/**
 * Adds two integers and returns the result.
 *
 * @param a the first number
 * @param b the second number
 * @return the sum of a and b
 */
public static int add(int a, int b) {
    return a + b;
}
```

> Всё, что внутри `/** ... */`, будет обработано Javadoc-генератором и превращено в HTML-документацию.

---

## 📚 Основные теги Javadoc

| Тег          | Назначение                             |
|--------------|----------------------------------------|
| `@param`     | Описание параметра метода              |
| `@return`    | Что возвращает метод                   |
| `@throws`    | Какие исключения может выбросить метод |
| `@author`    | Автор класса или метода                |
| `@version`   | Версия компонента                      |
| `@see`       | Ссылка на другой класс или метод       |
| `@deprecated`| Пометка, что элемент устарел           |

---

## 🧪 Как сгенерировать документацию

Если ты используешь командную строку:

```bash
javadoc AdditionOfTwoNumbers.java
```

→ Это создаст HTML-файлы с описанием твоего класса и методов.

В IDE (например, IntelliJ IDEA) — документация отображается прямо при наведении курсора или при автодополнении.

---

## 🎯 Почему это важно

- 📖 Код становится читаемым даже без открытия исходников
- 🧩 Упрощает командную работу и open-source публикации
- 🛠️ Помогает IDE и другим инструментам понимать твой код
- 🧠 Формирует привычку **писать код как интерфейс**, а не просто как реализацию
