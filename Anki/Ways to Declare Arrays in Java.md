Способы объявления массивов в Java

В Java есть несколько способов объявления массивов. Вот основные из них:

## 1. Объявление с последующей инициализацией

```java
// Объявление массива
int[] numbers;
String[] names;

// Инициализация с указанием размера
numbers = new int[5]; // массив из 5 элементов
names = new String[3]; // массив из 3 элементов
```

## 2. Объявление и инициализация в одной строке

```java
// С указанием размера
int[] numbers = new int[5];
String[] names = new String[3];

// С непосредственным заполнением значений
int[] numbers = {1, 2, 3, 4, 5};
String[] names = {"Alice", "Bob", "Charlie"};
```

## 3. Для разных типов данных

```java
// Целочисленные массивы
int[] intArray = new int[10];
long[] longArray = {1L, 2L, 3L};

// Массивы с плавающей точкой
double[] doubleArray = new double[5];
float[] floatArray = {1.0f, 2.5f, 3.7f};

// Символьный массив
char[] charArray = {'a', 'b', 'c'};

// Логический массив
boolean[] boolArray = new boolean[2];
```

## 4. Многомерные массивы

```java
// Двумерный массив
int[][] matrix = new int[3][3]; // 3x3 матрица

// Инициализация с значениями
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// Трехмерный массив
int[][][] cube = new int[2][3][4];
```

## 5. Особенности массивов в Java

- **Размер фиксирован** после создания
- **Индексация начинается с 0**
- **Длина массива** доступна через свойство `.length`

```java
int[] arr = {1, 2, 3, 4, 5};
System.out.println(arr.length); // Выведет: 5
System.out.println(arr[0]);    // Выведет: 1 (первый элемент)
```

## 6. Динамическое создание массива

```java
// Создание массива на основе переменной
int size = 10;
int[] dynamicArray = new int[size];
```

Выбор способа зависит от конкретной ситуации: если значения известны заранее, используйте сокращенную форму с фигурными скобками, если размер известен, но значения будут заполняться позже - используйте форму с `new`.
