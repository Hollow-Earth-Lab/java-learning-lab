java.lang

java.lang — базовый пакет Java, автоматически импортируемый во все классы. Содержит фундаментальные классы и интерфейсы, которые нужны при любой разработке на Java. Основные группы и наиболее важные типы:

- Классы ядра
  - Object — общий предок всех классов; equals(), hashCode(), toString(), wait/notify и т.д.
  - Class — метаданные о классах во время выполнения.
  - System — ввод/вывод консоли, свойства среды, загрузчик классов; содержит поля in/out/err и методы currentTimeMillis(), getenv(), exit().
  - Runtime — доступ к среде выполнения JVM (память, завершение, запуск процессов).
  - RuntimeException / Exception / Error — иерархия исключений и ошибок.

- Примитивные-обёртки (wrapper classes)
  - Byte, Short, Integer, Long, Float, Double, Character, Boolean — позволяют работать с примитивами как с объектами; содержат парсинг, константы MIN_VALUE/MAX_VALUE и автопаковку/распаковку.

- Строки и работа с символами
  - String — неизменяемая последовательность символов; наиболее используемый класс.
  - StringBuilder, StringBuffer — изменяемые последовательности символов (StringBuilder не синхронизирован, быстрее в однопоточной работе).
  - Character — утилиты для работы с символами (категории, преобразования регистра).

- Объекты и ссылки
  - Object (см. выше)
  - Enum — базовый класс для перечислений; позволяет определить ограниченный набор констант.
  - ClassLoader — загрузка классов динамически.
  - Package — информация о пакете класса.
  - Process — управление запущенными процессами.

- Потоки управления и многопоточность
  - Thread — поток исполнения; методы start(), run(), interrupt(), join() и т.д.
  - Runnable — функциональный интерфейс для задания кода потока.
  - ThreadLocal — переменные, локальные для потока.
  - StackOverflowError, InterruptedException (исключения/ошибки, связанные с потоками).

- Математические и утилитные классы
  - Math, StrictMath — математические функции (sin, cos, pow, random).
  - StrictMath — гарантированная платформонезависимая точность.
  - Object native methods и прочие низкоуровневые утилиты.

- Сравнение и сопоставление
  - Comparable<T> — интерфейс для естественного порядка.
  - Comparable и ComparableFuture? (ошибка) — (игнорируйте).
  - (корректно) Comparable и CharSequence — интерфейсы для сравнения и представления последовательностей символов.
  - Comparable, and Comparator are in java.util (Comparator — не в java.lang).

- Конверсия и парсинг
  - String.valueOf(), parseInt() у Integer и др. (частично в wrapper-классах).

- Рефлексия/инструменты классов
  - Class (см. выше) — получение методов, полей, конструкторов; вызов через reflection API (java.lang.reflect расширяет функциональность).

- Аннотации и вспомогательные типы
  - Deprecated, Override, SafeVarargs, FunctionalInterface — некоторые стандартные аннотации находятся в java.lang.
  - Thread.State — вложенный enum в Thread для состояния потока.

Дополнительные заметки:
- java.lang автоматически импортируется — нет нужды прописывать import для классов этого пакета.
- Классы в java.lang оптимизированы и тесно связаны с JVM; некоторые реализованы нативно (на уровне JVM) для производительности.
- Не используйте внутренние неопубликованные API (com.sun.* / sun.*) — они не являются частью java.lang и ненадёжны.
