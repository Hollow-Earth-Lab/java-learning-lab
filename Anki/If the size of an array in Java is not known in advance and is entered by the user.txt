Если размер массива в Java неизвестен заранее и вводится пользователем

Если размер массива в Java неизвестен заранее и вводится пользователем, вот как это реализовать:

## 1. Базовый пример с Scanner

```java
import java.util.Scanner;

public class DynamicArrayExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // Запрашиваем размер у пользователя
        System.out.print("Введите размер массива: ");
        int size = scanner.nextInt();
        
        // Создаем массив нужного размера
        int[] numbers = new int[size];
        
        // Заполняем массив значениями
        System.out.println("Введите " + size + " чисел:");
        for (int i = 0; i < size; i++) {
            numbers[i] = scanner.nextInt();
        }
        
        // Выводим результат
        System.out.println("Ваш массив:");
        for (int i = 0; i < numbers.length; i++) {
            System.out.println("numbers[" + i + "] = " + numbers[i]);
        }
        
        scanner.close();
    }
}
```

## 2. Пример с обработкой ошибок

```java
import java.util.Scanner;

public class SafeArrayInput {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int size = 0;
        
        // Запрос размера с проверкой корректности
        boolean validInput = false;
        while (!validInput) {
            try {
                System.out.print("Введите размер массива (положительное число): ");
                size = scanner.nextInt();
                
                if (size > 0) {
                    validInput = true;
                } else {
                    System.out.println("Размер должен быть положительным числом!");
                }
            } catch (Exception e) {
                System.out.println("Ошибка! Введите целое число.");
                scanner.next(); // Очищаем некорректный ввод
            }
        }
        
        // Создаем и заполняем массив
        String[] names = new String[size];
        scanner.nextLine(); // Очищаем буфер
        
        System.out.println("Введите " + size + " имен:");
        for (int i = 0; i < size; i++) {
            System.out.print("Имя " + (i + 1) + ": ");
            names[i] = scanner.nextLine();
        }
        
        // Вывод результата
        System.out.println("\nСписок имен:");
        for (String name : names) {
            System.out.println(name);
        }
        
        scanner.close();
    }
}
```

## 3. Более сложный пример с динамическим типом данных

```java
import java.util.Scanner;

public class FlexibleArray {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Введите размер массива: ");
        int size = scanner.nextInt();
        
        System.out.print("Выберите тип данных (1 - int, 2 - double, 3 - String): ");
        int choice = scanner.nextInt();
        
        scanner.nextLine(); // Очищаем буфер
        
        if (choice == 1) {
            int[] intArray = new int[size];
            System.out.println("Введите " + size + " целых чисел:");
            for (int i = 0; i < size; i++) {
                intArray[i] = scanner.nextInt();
            }
            // Работа с int массивом
        } else if (choice == 2) {
            double[] doubleArray = new double[size];
            System.out.println("Введите " + size + " дробных чисел:");
            for (int i = 0; i < size; i++) {
                doubleArray[i] = scanner.nextDouble();
            }
            // Работа с double массивом
        } else if (choice == 3) {
            String[] stringArray = new String[size];
            System.out.println("Введите " + size + " строк:");
            for (int i = 0; i < size; i++) {
                stringArray[i] = scanner.nextLine();
            }
            // Работа со string массивом
        }
        
        scanner.close();
    }
}
```

## 4. Пример с вычислениями над массивом

```java
import java.util.Scanner;

public class ArrayCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        System.out.print("Введите количество чисел: ");
        int size = scanner.nextInt();
        
        double[] numbers = new double[size];
        
        System.out.println("Введите " + size + " чисел:");
        for (int i = 0; i < size; i++) {
            numbers[i] = scanner.nextDouble();
        }
        
        // Вычисления
        double sum = 0;
        double max = numbers[0];
        double min = numbers[0];
        
        for (double num : numbers) {
            sum += num;
            if (num > max) max = num;
            if (num < min) min = num;
        }
        
        double average = sum / size;
        
        System.out.println("Результаты:");
        System.out.println("Сумма: " + sum);
        System.out.println("Среднее: " + average);
        System.out.println("Максимум: " + max);
        System.out.println("Минимум: " + min);
        
        scanner.close();
    }
}
```

## Важные моменты:

1. **Всегда проверяйте ввод** - пользователь может ввести некорректные данные
2. **Закрывайте Scanner** с помощью `scanner.close()`
3. **Очищайте буфер** после `nextInt()` с помощью `scanner.nextLine()`
4. **Размер массива фиксирован** после создания - нельзя изменить

Если нужна динамически изменяемая структура, лучше использовать `ArrayList` вместо массива.
