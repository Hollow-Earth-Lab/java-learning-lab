Отличный вопрос 👍
Теперь разберём **overloading (перегрузку методов)** в Java.

---

## 🔑 Что такое overloading (перегрузка)

Перегрузка — это когда в **одном классе** несколько методов имеют **одно и то же имя**, но **разные параметры** (количество или типы).
Компилятор сам выбирает, какой метод вызвать, основываясь на переданных аргументах.

---

## 📌 Основные правила

1. Имя метода — одинаковое.
2. Список параметров — разный (**число, порядок или типы аргументов**).
3. Возвращаемый тип **не участвует** в выборе метода (нельзя перегрузить только изменив `return`).
4. Перегруженные методы могут иметь разные модификаторы доступа и разные `throws`-исключения.

---

## 📖 Пример перегрузки

```java
class Calculator {
    // сложение двух int
    int add(int a, int b) {
        return a + b;
    }

    // сложение трёх int
    int add(int a, int b, int c) {
        return a + b + c;
    }

    // сложение двух double
    double add(double a, double b) {
        return a + b;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calc = new Calculator();

        System.out.println(calc.add(2, 3));        // вызывает add(int, int)
        System.out.println(calc.add(1, 2, 3));     // вызывает add(int, int, int)
        System.out.println(calc.add(2.5, 3.7));    // вызывает add(double, double)
    }
}
```

👉 Результат:

```
5
6
6.2
```

---

## ⚡ Автоматическое преобразование типов

Java может выбрать перегруженный метод, применив приведение типов (widening, autoboxing, varargs).

Пример:

```java
void print(int x)   { System.out.println("int: " + x); }
void print(double y){ System.out.println("double: " + y); }
void print(Integer z){ System.out.println("Integer: " + z); }

print(5);     // int → вызывает print(int)
print(5L);    // long → widening до double → print(double)
print(null);  // null → вызывает print(Integer), т.к. объект
```

---

## 🔄 Отличие от Overriding

| Overloading (перегрузка)               | Overriding (переопределение)                     |
| -------------------------------------- | ------------------------------------------------ |
| В одном классе                         | В наследниках                                    |
| Разные параметры                       | Одинаковая сигнатура                             |
| Выбор метода — **на этапе компиляции** | Выбор метода — **во время выполнения (runtime)** |
| Не связан с наследованием              | Связан с наследованием                           |

---

💡 **Вывод:**
Overloading — это способ сделать интерфейс класса удобнее, позволяя вызывать методы с одним и тем же названием, но разными наборами аргументов.
