public

`public` в Java это **модификатор доступа**, который определяет, кто может использовать класс, метод или переменную. 
Вот краткий, архитектурно выразительный разбор:

---

## ✅ Что означает `public` в Java

- **Доступен отовсюду**: из любого другого класса, пакета, модуля
- Применяется к:
  - Классам
  - Методам
  - Переменным
  - Конструкторам

---

## 📦 Примеры использования

### 1. `public class DigitSumCalculator`
```java
public class DigitSumCalculator {
    // доступен из любого места
}
```

→ Класс можно использовать из других пакетов.

---

### 2. `public static void main(String[] args)`
```java
public static void main(String[] args) {
    // точка входа в программу
}
```

→ Метод `main` должен быть `public`, иначе JVM не сможет его вызвать.

---

### 3. `public int calculateDigitSum(int number)`
```java
public int calculateDigitSum(int number) {
    // можно вызвать из другого класса
}
```

→ Метод доступен для вызова извне.

---

## 🧠 Сравнение с другими модификаторами

| Модификатор | Доступность                          |
|-------------|--------------------------------------|
| `public`    | Везде                                |
| `protected` | Внутри пакета и подклассах           |
| `default`   | Только внутри пакета (если без модификатора) |
| `private`   | Только внутри текущего класса        |

---

## 🎯 Когда использовать `public`

- Когда ты хочешь, чтобы класс или метод был **доступен извне**
- Когда ты создаёшь **API, утилиты, модули**
- Когда метод — **точка входа** (`main`)
