int

Тип `int` — это один из **примитивных типов**, и он играет ключевую роль в любой Java-программе, особенно когда речь идёт о счётчиках, индексах, арифметике и логике.

---

## 🔹 Что такое `int` в Java

- `int` (от *integer*) — это **32-битный целочисленный тип**, предназначенный для хранения **целых чисел без дробной части**.
- Диапазон значений: от **−2,147,483,648** до **2,147,483,647**
- Занимает **4 байта** в памяти
- Является **знаковым** — поддерживает как положительные, так и отрицательные числа

```java
int a = 42;
int b = -100;
int sum = a + b;
```

---

## 🧠 Особенности

- Все **целочисленные литералы** по умолчанию интерпретируются как `int`:
  ```java
  int x = 100; // OK
  long y = 2147483649; // Ошибка, если не указать L
  long y = 2147483649L; // OK
  ```

- `int` — это **самый часто используемый тип** для:
  - Счётчиков в циклах (`for (int i = 0; i < n; i++)`)
  - Индексов массивов
  - Простых арифметических операций

---

## 🔧 Системы счисления

Ты можешь задавать `int` в разных системах:

```java
int decimal = 42;       // десятичная
int binary = 0b101010;  // двоичная
int octal = 052;        // восьмеричная
int hex = 0x2A;         // шестнадцатеричная
```

→ Все эти значения равны `42`.

---

## ⚠️ Ограничения

- `int` не может хранить дробные числа — для этого есть `double` или `float`
- При переполнении диапазона происходит **обрезка**:
  ```java
  int x = Integer.MAX_VALUE + 1; // результат: Integer.MIN_VALUE
  ```

→ Это называется **переполнение**, и его нужно учитывать при работе с большими числами.

---

## 🎯 Когда использовать `int`

- Когда тебе нужны **целые числа** в пределах ±2 миллиарда
- Когда важна **производительность** — `int` быстрее, чем `long` или `BigInteger`
- Когда ты строишь **структуры управления**: циклы, индексы, флаги
