package

## 📦 `package` в Java — это **механизм организации классов**

Он позволяет группировать связанные классы, интерфейсы и перечисления в логические блоки. Это как папки в файловой системе, но внутри кода.

---

## ✅ Пример объявления пакета

```java
package com.hollow.math;

public class DigitSumCalculator {
    // ...
}
```

→ Класс `DigitSumCalculator` теперь принадлежит пакету `com.hollow.math`

---

## 🧠 Зачем нужны пакеты

- 📂 Организация кода: логическая структура проекта
- 🔐 Контроль доступа: `protected` и `default` работают внутри пакета
- 📦 Импорт классов: можно использовать `import` для доступа к другим пакетам
- 🌍 Уникальные имена: предотвращают конфликты между классами с одинаковыми именами

---

## 📥 Импорт классов из пакета

```java
import com.hollow.math.DigitSumCalculator;
```

→ Позволяет использовать класс без полного имени

---

## 🧩 Структура проекта с пакетами

```
src/
└── com/
    └── hollow/
        └── math/
            └── DigitSumCalculator.java
```

→ Папки соответствуют имени пакета

---

## ⚠️ А что такое `packet`?

Если ты имел в виду `packet`, то это **сетевой термин** — например, IP-пакет, TCP-пакет. В Java это может относиться к:

- `DatagramPacket` — класс для UDP-пакетов
- `Socket` / `ServerSocket` — работа с TCP

Если ты хочешь именно про сетевые пакеты — я могу углубиться в `DatagramPacket`, `ByteBuffer`, или `Netty`.
