В Java метод `main` **всегда должен быть `public static void`**

В Java метод `main` **всегда должен быть `public static void`**, чтобы JVM (Java Virtual Machine) могла его найти и запустить. Это не просто соглашение, а **жёсткое требование спецификации языка**.

---

## 📦 Почему именно `public static void main(String[] args)`

| Компонент       | Зачем нужен                            |
|-----------------|----------------------------------------|
| `public`        | Доступен JVM извне                     |
| `static`        | Вызывается без создания объекта класса |
| `void`          | Не возвращает значение                 |
| `main`          | Зарезервированное имя точки входа      |
| `String[] args` | Аргументы командной строки             |

---

## ⚠️ Что будет, если изменить сигнатуру?

### ❌ Убрать `public`
```java
static void main(String[] args) { ... }
```
→ JVM не сможет найти метод → `Main method not found`

### ❌ Убрать `static`
```java
public void main(String[] args) { ... }
```
→ JVM не сможет вызвать метод без создания объекта → ошибка

### ❌ Изменить `void`
```java
public static int main(String[] args) { ... }
```
→ JVM ожидает `void` → ошибка

---

## 🧠 Альтернативы — только для экспериментов

Ты можешь создать **перегруженные версии** `main`, но они не будут точкой входа:

```java
public static void main() { ... }         // не вызывается при запуске
public static void main(String arg) { ... } // тоже нет
```

→ JVM ищет **только** `public static void main(String[] args)`
