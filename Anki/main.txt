main

`main` это **специальный метод**, с которого начинается выполнение программы. Вот подробный разбор:

---

## ✅ Что такое `main` в Java

Это **точка входа** для JVM (Java Virtual Machine). Именно этот метод вызывается при запуске программы.

```java
public static void main(String[] args) {
    // код, который выполняется при запуске
}
```

---

## 📦 Разбор по компонентам

| Часть           | Значение                                      |
|-----------------|-----------------------------------------------|
| `public`        | Доступен JVM извне                            |
| `static`        | Вызывается без создания объекта               |
| `void`          | Не возвращает значение                        |
| `main`          | Имя метода, зарезервированное для точки входа |
| `String[] args` | Массив аргументов командной строки            |

---

## 🧠 Пример использования аргументов

```java
public static void main(String[] args) {
    if (args.length > 0) {
        System.out.println("First argument: " + args[0]);
    } else {
        System.out.println("No arguments provided.");
    }
}
```

→ Позволяет передавать параметры при запуске:  
```bash
java MyProgram Hello
```

---

## 🎯 Где используется `main`

- В **консольных приложениях**
- В **тестовых модулях**
- В **учебных примерах**
- В **точке входа для запуска GUI или серверов**

---

## 🧩 Альтернатива в больших системах

В более сложных системах `main` может просто запускать **инициализатор**, например:

```java
public static void main(String[] args) {
    Application.run();
}
```

→ Это делает архитектуру модульной и расширяемой
