static

`static` в Java это **модификатор**, который означает, что элемент принадлежит **классу**, а не конкретному объекту. Вот архитектурно точный разбор:

---

## ✅ Что делает `static` в Java

- Привязывает поле или метод **к классу**, а не к экземпляру
- Позволяет вызывать метод или обращаться к переменной **без создания объекта**
- Используется для:
  - `main()` — точка входа
  - Утилит и констант
  - Общих счётчиков, кешей, фабрик

---

## 📦 Примеры

### 1. `static` метод

```java
public class MathUtils {
    public static int square(int x) {
        return x * x;
    }
}
```

→ Вызывается как: `MathUtils.square(5)`

---

### 2. `static` переменная

```java
public class Counter {
    public static int total = 0;
}
```

→ Доступ: `Counter.total`

---

### 3. `static` блок инициализации

```java
static {
    System.out.println("Class loaded");
}
```

→ Выполняется один раз при загрузке класса

---

### 4. `static` вложенный класс

```java
public class Outer {
    public static class Inner {
        // ...
    }
}
```

→ Можно создать `new Outer.Inner()` без экземпляра `Outer`

---

## 🧠 Почему это важно

| Признак                     | `static` означает...                     |
|----------------------------|------------------------------------------|
| Не зависит от объекта      | Можно использовать без `new`             |
| Общий для всех экземпляров | Делит память между объектами             |
| Загружается при старте     | Инициализируется при загрузке класса     |

---

## 🎯 Когда использовать `static`

- Для **утилит**: `Math`, `Arrays`, `Collections`
- Для **точки входа**: `main(String[] args)`
- Для **констант**: `public static final int MAX = 100;`
- Для **общих счётчиков**: `static int count = 0;`
