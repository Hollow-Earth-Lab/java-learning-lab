method overriding

Оверрайдинг в Java — это один из ключевых механизмов **полиморфизма**, когда **подкласс переопределяет метод суперкласса** для изменения или уточнения его поведения.

---

## 🔑 Основные моменты

1. **Что такое overriding**

   * В суперклассе есть метод.
   * Подкласс пишет метод с **той же сигнатурой** (имя, параметры, возвращаемый тип).
   * При вызове метода на объекте подкласса будет использоваться именно переопределённая версия.

---

2. **Правила overriding**

   * Имя метода и список параметров должны совпадать.
   * Возвращаемый тип:

     * До Java 5: должен быть **точно таким же**.
     * С Java 5: можно использовать **ковариантный тип** (например, в суперклассе возвращается `Number`, а в подклассе — `Integer`).
   * Модификатор доступа:

     * Нельзя делать доступ более строгим (если `public` в суперклассе, то в подклассе тоже минимум `public`).
     * Можно ослаблять ограничение (например, `protected` → `public`).
   * Методы с `final`, `static` или `private` нельзя переопределять.
   * Допустимые исключения:

     * Подкласс может выбрасывать **меньше или более конкретные** checked-исключения.

---

3. **Аннотация `@Override`**

   * Используется для явного указания, что метод переопределяется.
   * Помогает компилятору ловить ошибки (например, если опечататься в имени метода, компилятор выдаст ошибку).

---

4. **Пример**

```java
class Animal {
    void sound() {
        System.out.println("Животное издаёт звук");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Собака лает");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Animal();
        Animal d = new Dog();

        a.sound(); // "Животное издаёт звук"
        d.sound(); // "Собака лает" (сработал overriding)
    }
}
```

---

5. **Отличие от Overloading (перегрузки методов)**

* **Overriding** — переопределение в **наследниках**, сигнатура та же, меняется поведение.
* **Overloading** — перегрузка в **одном классе**, имя метода то же, но разные параметры.

---

💡 **Вывод:**
Overriding — это инструмент для реализации полиморфизма: позволяет подклаccам адаптировать поведение унаследованных методов под свои задачи.
