Java Core (или Java SE Core)

Основная часть платформы Java Standard Edition (Java SE), которая включает набор базовых библиотек, инструментов и API для разработки приложений на языке Java. Это фундамент, на котором строятся другие платформы, такие как Java EE или Java ME. Основные компоненты:

### 1. **Язык программирования Java**
   - Синтаксис языка (переменные, типы данных, операторы, управляющие конструкции).
   - Объектно-ориентированные принципы (классы, объекты, наследование, полиморфизм, инкапсуляция).
   - Особенности языка, такие как автоматическое управление памятью (сборка мусора), исключения, аннотации и т.д.

### 2. **Java Virtual Machine (JVM)**
   - Виртуальная машина Java, которая интерпретирует байт-код и выполняет программы.
   - Сборка мусора (Garbage Collection).
   - JIT-компиляция (Just-In-Time) для оптимизации производительности.

### 3. **Базовые библиотеки (Java API)**
   Это набор стандартных классов и интерфейсов, входящих в Java SE. Основные пакеты включают:
   - **`java.lang`**: Базовые классы, такие как `String`, `Object`, `System`, `Math`, `Thread`, а также обертки для примитивных типов (`Integer`, `Double` и т.д.).
   - **`java.util`**: Коллекции (List, Set, Map), утилиты для работы с датами (`Date`, `Calendar`), генерация случайных чисел (`Random`), работа с потоками данных (`Scanner`).
   - **`java.io`**: Работа с вводом-выводом (файлы, потоки).
   - **`java.nio`**: Более современные средства для работы с вводом-выводом, включая неблокирующий ввод-вывод.
   - **`java.net`**: Сетевые возможности (сокеты, URL, HTTP-запросы).
   - **`java.time`**: Современный API для работы с датами и временем (введен в Java 8).
   - **`java.math`**: Классы для работы с большими числами (`BigInteger`, `BigDecimal`).
   - **`java.text`**: Форматирование текста, чисел, дат.
   - **`java.security`**: Средства для обеспечения безопасности, криптографии.
   - **`java.util.concurrent`**: Средства для многопоточного программирования (ExecutorService, Fork/Join, Concurrent коллекции).

### 4. **Основные возможности языка**
   - **Многопоточность**: Поддержка потоков (`Thread`, `Runnable`, синхронизация).
   - **Обработка исключений**: Механизм `try-catch`, иерархия исключений (`Throwable`, `Exception`, `Error`).
   - **Рефлексия**: API для работы с метаданными классов (`java.lang.reflect`).
   - **Аннотации**: Поддержка метаданных через аннотации (например, `@Override`, `@Deprecated`).
   - **Лямбда-выражения и Stream API** (с Java 8): Функциональное программирование, работа с потоками данных.
   - **Модульность** (с Java 9): Система модулей (JPMS) для управления зависимостями.

### 5. **Инструменты JDK**
   - **`javac`**: Компилятор для преобразования исходного кода в байт-код.
   - **`java`**: Запуск Java-программ.
   - **`jar`**: Создание и управление архивами JAR.
   - **`javadoc`**: Генерация документации.
   - **`jdb`**: Отладчик.
   - Другие утилиты, такие как `jconsole`, `jvisualvm` для мониторинга и диагностики.

### 6. **Ключевые концепции**
   - **Платформонезависимость**: Принцип "пиши один раз, запускай везде" благодаря байт-коду и JVM.
   - **Сборка мусора**: Автоматическое управление памятью.
   - **Типобезопасность**: Строгая типизация и проверка типов на этапе компиляции.
   - **Обратная совместимость**: Java SE сохраняет совместимость с предыдущими версиями.
