double

Тип `double` — это один из примитивных типов, предназначенный для хранения **дробных чисел с высокой точностью**. Давай разложу по слоям, как ты любишь:

---

## 🔹 Что такое `double` в Java

- `double` — это **64-битный тип с плавающей точкой**, основанный на стандарте IEEE 754.
- Он может хранить числа с **десятичной частью**, например: `3.14`, `-0.001`, `2.718281828`.
- Диапазон значений:  
  от **±4.9 × 10⁻³²⁴** до **±1.7976931348623157 × 10³⁰⁸**
- Занимает **8 байт** в памяти.

```java
double pi = 3.14159;
double negative = -0.5;
double sum = pi + negative;
```

---

## 🧠 Особенности

- По умолчанию **дробные литералы интерпретируются как `double`**, если не указано `f` для `float`.
- Разделитель между целой и дробной частью — **точка (`.`)**, независимо от локали.
- Поддерживает все стандартные арифметические операции: `+`, `-`, `*`, `/`.

---

## ⚠️ Важные нюансы

### 🔧 Погрешность
`double` — это **приближённое представление**, не идеально точное. Например:

```java
System.out.println(0.1 + 0.2); // Вывод: 0.30000000000000004
```

→ Это связано с тем, что **некоторые дроби не представимы точно в двоичной системе**.

### 🔧 Сравнение
Из-за погрешности, сравнивать `double` лучше с допуском:

```java
if (Math.abs(a - b) < 1e-9) {
    // считаем числа равными
}
```

---

## 📚 Когда использовать `double`

- Когда тебе нужны **дробные числа**: физика, финансы, инженерные расчёты
- Когда диапазон значений может быть **очень большим или очень маленьким**
- Когда точность важнее, чем компактность (в отличие от `float`)

---

## 🧩 Альтернатива: `BigDecimal`

Если тебе нужна **абсолютная точность**, например, в банковских расчётах — лучше использовать `BigDecimal`. Он работает с **десятичной арифметикой**, без погрешностей, но требует больше кода и ресурсов.
