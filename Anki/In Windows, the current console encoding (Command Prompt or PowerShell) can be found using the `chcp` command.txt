chcp

В Windows текущую кодировку консоли (Command Prompt или PowerShell) можно узнать с помощью команды `chcp`. Вот как это сделать:

### 1. **Использование команды `chcp` в Command Prompt**
   - Откройте командную строку (Command Prompt).
   - Введите команду:
     ```cmd
     chcp
     ```
   - Вы получите вывод вида:
     ```
     Active code page: 866
     ```
     Здесь `866` — это текущая кодовая страница (например, CP866 для кириллицы в DOS). Для UTF-8 кодовая страница будет `65001`.

### 2. **Проверка в PowerShell**
   - Откройте PowerShell.
   - Выполните команду:
     ```powershell
     [System.Console]::OutputEncoding
     ```
     или
     ```powershell
     Get-Encoding
     ```
   - Вывод покажет текущую кодировку, например:
     ```
     BodyName         : utf-8
     EncodingName     : Unicode (UTF-8)
     ```
     Или, для более точной информации о кодовой странице:
     ```powershell
     chcp
     ```

### 3. **Типичные кодовые страницы**
   - `866`: Стандартная кодировка для кириллицы в Windows (CP866, часто используется в Command Prompt).
   - `1251`: Windows-1251, другая кодировка для кириллицы.
   - `65001`: UTF-8, современная кодировка, поддерживающая кириллицу и другие Unicode-символы.

### 4. **Проблемы с кириллицей**
Если в консоли отображаются "кракозябры" вместо кириллицы, это может быть связано с тем, что текущая кодировка (например, CP866) не соответствует кодировке текста (например, UTF-8). Чтобы временно установить UTF-8:
   - В Command Prompt:
     ```cmd
     chcp 65001
     ```
   - В PowerShell:
     ```powershell
     [System.Console]::OutputEncoding = [System.Text.Encoding]::UTF8
     ```

### 5. **Проверка в Java**
Если вы хотите узнать кодировку, используемую JVM для консоли, выполните следующий код:
```java
import java.nio.charset.Charset;

public class ConsoleEncoding {
    public static void main(String[] args) {
        System.out.println("Default Charset: " + Charset.defaultCharset());
        System.out.println("Console Output Encoding: " + System.getProperty("sun.stdout.encoding"));
    }
}
```
- `Charset.defaultCharset()` возвращает кодировку по умолчанию для JVM (зависит от настроек системы).
- `sun.stdout.encoding` показывает кодировку, используемую для вывода в консоль (может быть `cp866`, `windows-1251`, или `UTF-8`).

### 6. **Рекомендация**
Для корректной работы с кириллицей в консоли Windows:
- Установите UTF-8 (`chcp 65001`) перед запуском Java-программы.
- Убедитесь, что ваш код использует `StandardCharsets.UTF_8` для ввода-вывода (как описано в предыдущем ответе).
- Если используете IDE (например, IntelliJ IDEA), проверьте настройки консоли в IDE, чтобы она также использовала UTF-8.
