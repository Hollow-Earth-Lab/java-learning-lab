## ✅ Что такое `class` в Java

`class` — это **шаблон (или чертёж)** для создания объектов. Он описывает:

- 🧠 **Состояние** объекта — через поля (переменные)
- ⚙️ **Поведение** — через методы
- 🏗️ **Конструкторы** — как создавать экземпляры

---

## 📦 Пример простого класса

```java
public class Person {
    String name;
    int age;

    public void greet() {
        System.out.println("Hello, my name is " + name);
    }
}
```

→ Это шаблон для объектов типа `Person`

---

## 🧠 Создание объекта из класса

```java
Person p = new Person();
p.name = "Hollow";
p.age = 30;
p.greet(); // → Hello, my name is Hollow
```

→ Объект `p` — это экземпляр класса `Person`

---

## 🎯 Структура класса

```java
[модификатор доступа] class [Имя] {
    // поля
    // конструкторы
    // методы
    // вложенные классы (если нужно)
}
```

---

## 🧩 Виды классов

|  Вид класса      | Описание                                             |
|------------------|------------------------------------------------------|
| `public class`   | Доступен из любого места                             |
| `abstract class` | Нельзя создать напрямую, содержит абстрактные методы |
| `final class`    | Нельзя наследовать                                   |
| `static class`   | Вложенный, не требует экземпляра внешнего класса     |
| `enum`           | Перечисление фиксированных значений                  |
| `record`         | Иммутабельный класс с автогенерацией `equals`, `hashCode`, `toString` |

## 📂 Организация классов по пакетам

```java
package com.hollow.math;

public class DigitSumCalculator {
    // ...
}
```

→ Это помогает структурировать проект и управлять доступом

---

Класс *может* быть в отдельном `.java`-файле, но **не обязан**, если соблюдены определённые правила.

---

## ✅ Когда класс должен быть в отдельном файле

Если класс **`public`**, то:

```java
public class DigitSumCalculator { ... }
```

🔒 Он **обязан** находиться в файле с таким же именем:

```
DigitSumCalculator.java
```

→ Это требование компилятора: имя файла должно совпадать с именем `public`-класса.

---

## 🧩 Когда можно иметь несколько классов в одном файле

```java
class Helper { ... }

class DigitSumCalculator { ... }
```

✅ Если **ни один из классов не `public`**, ты можешь держать их в одном `.java`-файле.

→ Это удобно для вспомогательных классов, особенно если они используются только внутри одного модуля.

---

## 📦 Вложенные классы

Ты можешь объявлять классы **внутри других классов**:

```java
public class Outer {
    static class Inner { ... }
}
```

→ Вложенные классы не требуют отдельного файла.

---

## 🎯 Резюме

| Сценарий                                | Требуется отдельный файл |
|-----------------------------------------|--------------------------|
| `public class`                          | ✅ Да                    |
| Несколько `package-private` классов     | ❌ Нет                   |
| Вложенные классы (`static` или обычные) | ❌ Нет                   |
