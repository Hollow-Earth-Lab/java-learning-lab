# 🃏 Карточка новичка в Java

## 1. Минимум для старта

* Установи **JDK (Java Development Kit)** и среду (IntelliJ IDEA Community или VS Code с плагином).
* Напиши класс `HelloWorld` с `public static void main(String[] args)` — это твоя точка входа.

---

## 2. Базовые кирпичики

* **Типы данных**: `int`, `double`, `char`, `boolean`, `String`.
* **Операторы**: `+ - * / %`, сравнения (`==`, `!=`, `>`, `<`) и логические (`&&`, `||`, `!`).
* **Условие**: `if/else`, `switch`.
* **Циклы**: `for`, `while`, `do-while`, `for-each`.
* **Массивы**: `int[] nums = {1,2,3};`.

---

## 3. Основы ООП

* **Классы и объекты**: `new` для создания.
* **Поля и методы**: переменные + поведение.
* **Модификаторы доступа**: `public`, `private`, `protected`.
* **Конструктор**: метод для инициализации объекта.
* **Наследование**: `extends`.
* **Интерфейсы**: `implements`.

---

## 4. Практика для закрепления

🔹 Напиши маленькие программы:

* Калькулятор (сложение, вычитание, умножение, деление).
* Факториал числа.
* Сумма цифр числа.
* Проверка числа на простоту.
* Работа со строками (палиндром, подсчёт символов).

---

## 5. Что освоить дальше

* **Коллекции**: `ArrayList`, `HashMap`, `HashSet`.
* **Generics** (обобщения).
* **Exceptions** (исключения: `try-catch-finally`).
* **Streams API** (работа с данными в функциональном стиле).
* **Java I/O** (чтение/запись файлов).

---

## 6. Типичные ошибки новичков

❌ Путают `==` и `.equals()` для строк.
❌ Забывают про `null` (получают `NullPointerException`).
❌ Делают всё в `main`, вместо того чтобы выносить в методы/классы.
❌ Не понимают область видимости переменных.

### С чего начать

1.  **Установите необходимое ПО.** Вам понадобится **JDK (Java Development Kit)** — это основной набор инструментов разработчика. Сегодня самая актуальная версия с долгосрочной поддержкой (LTS) — **Java 21**, но многие проекты всё ещё используют **Java 17** и **Java 8**. Начните с Java 17 или 21. Затем установите **IDE (Integrated Development Environment)**, например, **IntelliJ IDEA Community Edition**, которая является отраслевым стандартом и очень удобна для новичков.

2.  **Выучите синтаксис.** Изучите основные строительные блоки языка:
    * **Переменные** и **типы данных** (примитивные вроде `int`, `double`, `boolean` и ссылочные).
    * **Операторы** (арифметические, логические, сравнения).

    * **Инкапсуляция** (сокрытие данных).
    * **Наследование** (повторное использование кода).
    * **Полиморфизм** (один интерфейс, множество реализаций).
    * **Абстракция** (выделение важных деталей).

4.  **Разберитесь с коллекциями.** После того как вы освоите базовые типы, изучите, как хранить и обрабатывать группы объектов с помощью стандартных коллекций Java: **`List`**, **`Set`** и **`Map`**.

### База, которую нужно знать наизусть

Это тот фундамент, который должен знать каждый Java-разработчик.

#### 1. Основы JVM
* **Что такое JVM (Java Virtual Machine):** среда выполнения, которая позволяет Java-коду работать на любой платформе.
* **Как происходит компиляция:** исходный код (`.java`) компилируется в байт-код (`.class`), который затем выполняется на JVM.

#### 2. Типы данных и переменные
* **Примитивные типы:** `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`.
* **Ссылочные типы:** классы, интерфейсы, массивы.
* **Автоупаковка и распаковка (Autoboxing/Unboxing):** автоматическое преобразование между примитивными типами и их классами-обёртками (`int` -> `Integer`).

#### 3. Объектно-ориентированное программирование
* **Классы и объекты:** как их создавать и использовать.
* **Конструкторы:** их назначение и правила создания.
* **Методы и их сигнатуры:** как объявлять, перегружать (`overloading`) и переопределять (`overriding`).
* **Ключевые слова:** `this`, `super`, `static`, `final`.
* **Модификаторы доступа:** `public`, `protected`, `private`, (по умолчанию).

#### 4. Обработка ошибок
* **Иерархия исключений:** `Exception`, `RuntimeException` и `Error`.
* **Ключевые слова:** `try`, `catch`, `finally`, `throw`, `throws`.
* **Checked vs Unchecked исключения:** понимание, когда исключение нужно обязательно обрабатывать.

#### 5. Коллекции Java (Java Collections Framework)
* **Интерфейсы:** `List` (упорядоченная коллекция), `Set` (коллекция уникальных элементов), `Map` (коллекция пар "ключ-значение").
* **Наиболее популярные реализации:** `ArrayList`, `HashSet`, `HashMap`.
* **Итераторы:** как перебирать элементы коллекций.

1. Основы синтаксиса

Переменные и типы данных:
Примитивные типы: int, double, boolean, char, long, float, byte, short.
Ссылочные типы: String, массивы, классы.
Пример: int age = 25; String name = "Alice";

Операторы: арифметические (+, -, *, /), логические (&&, ||, !), сравнения (==, !=, >, <).
Условия: if, else, switch.
Пример: if (age >= 18) {
    System.out.println("Совершеннолетний");
} else {
    System.out.println("Несовершеннолетний");
}

Циклы: for, while, do-while.
Пример: for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

2. Объектно-ориентированное программирование (ООП)

Классы и объекты: класс — шаблон, объект — экземпляр класса.
Пример: class Car {
    String model;
    int speed;
    void drive() {
        System.out.println(model + " едет со скоростью " + speed);
    }
}
Car myCar = new Car(); // Создание объекта
myCar.model = "Toyota";
myCar.speed = 100;
myCar.drive();

Основные принципы ООП:
Инкапсуляция: использование модификаторов доступа (private, public, protected) и геттеров/сеттеров.
Наследование: extends для создания подклассов.
Полиморфизм: переопределение методов (@Override).
Абстракция: абстрактные классы и интерфейсы.

3. Работа с данными

Массивы: int[] numbers = {1, 2, 3};
Коллекции: ArrayList, HashMap (например, ArrayList<String> list = new ArrayList<>();).
Обработка строк: методы String (например, length(), substring(), toUpperCase()).

4. Обработка исключений

Используй try-catch для обработки ошибок.
Пример:try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Деление на ноль!");
}
