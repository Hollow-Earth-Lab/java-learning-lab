Как сделать так, чтобы программа на Java выводила в консоль Windows сообщения на русском языке?

Чтобы программа на Java корректно выводила сообщения на русском языке в консоль Windows, нужно учесть кодировку консоли, так как Windows по умолчанию использует кодировку CP866 для консоли, а Java — UTF-8. Вот пошаговое решение:

1. **Установить кодировку вывода в UTF-8**:
   В Windows начиная с Java 11 можно задать кодировку консоли программно. Добавьте следующий код в начало вашей программы:

   ```java
   import java.nio.charset.StandardCharsets;

   public class Main {
       public static void main(String[] args) {
           // Устанавливаем кодировку консоли в UTF-8
           System.setOut(new java.io.PrintStream(System.out, true, StandardCharsets.UTF_8));
           System.out.println("Привет, мир!");
       }
   }
   ```

   Это заставляет Java использовать UTF-8 для вывода в консоль.

2. **Настроить консоль Windows**:
   Консоль Windows должна поддерживать UTF-8. Выполните следующую команду в командной строке перед запуском программы:

   ```cmd
   chcp 65001
   ```

   Это переключает кодировку консоли на UTF-8. Однако это нужно делать каждый раз при открытии новой консоли, либо можно настроить это глобально (см. ниже).

3. **Глобальная настройка кодировки в Windows**:
   Чтобы консоль всегда использовала UTF-8:
   - Откройте настройки Windows → "Язык и регион" → "Административные языковые параметры".
   - В разделе "Смена языка системы" включите опцию "Бета: Использовать Unicode UTF-8 для поддержки языков по всему миру".
   - Перезагрузите компьютер.

4. **Убедитесь, что шрифт консоли поддерживает кириллицу**:
   В консоли Windows (cmd или PowerShell) используйте шрифт, поддерживающий кириллицу, например, Consolas или Lucida Console:
   - Щелкните правой кнопкой мыши на заголовке окна консоли → "Свойства" → "Шрифт".
   - Выберите подходящий шрифт.

5. **Альтернативный способ — использовать PrintWriter**:
   Если первый способ не работает, можно использовать `PrintWriter` для явного указания кодировки:

   ```java
   import java.io.PrintWriter;
   import java.nio.charset.StandardCharsets;

   public class Main {
       public static void main(String[] args) {
           PrintWriter out = new PrintWriter(System.out, true, StandardCharsets.UTF_8);
           out.println("Привет, мир!");
       }
   }
   ```

6. **Проверка исходного кода**:
   Убедитесь, что ваш файл с исходным кодом (.java) сохранен в кодировке UTF-8. В большинстве IDE (например, IntelliJ IDEA или Eclipse) это значение по умолчанию, но стоит проверить настройки проекта.

7. **Запуск программы**:
   Если вы компилируете и запускаете программу через командную строку, используйте команду:

   ```cmd
   java -Dfile.encoding=UTF-8 Main
   ```

   Это дополнительно указывает JVM использовать UTF-8.

### Примечания:
- Если вы используете IDE, консоль внутри IDE обычно уже настроена на UTF-8, и проблемы могут возникать только при запуске через cmd.
- Если текст все равно отображается некорректно (например, вместо русских букв выводятся "???"), проверьте, правильно ли настроена кодировка как в программе, так и в консоли.
