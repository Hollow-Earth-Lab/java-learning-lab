void

`void` в Java это **тип возвращаемого значения**, который означает: **ничего не возвращается**. Вот архитектурно точный разбор:

---

## ✅ Что означает `void`

- Метод **не возвращает значение**
- Используется, когда метод выполняет действие (например, печать, изменение состояния), но **не даёт результат**
- Это **не тип данных**, а **указание компилятору**, что `return` не нужен

---

## 📦 Пример

```java
public void greet(String name) {
    System.out.println("Hello, " + name);
}
```

→ Метод `greet()` просто печатает приветствие, но ничего не возвращает

---

## 🧠 Сравнение с другими типами

| Возвращаемый тип | Описание                            |
|------------------|-------------------------------------|
| `void`           | Ничего не возвращает                |
| `int`            | Возвращает целое число              |
| `String`         | Возвращает строку                   |
| `boolean`        | Возвращает `true` или `false`       |
| `MyClass`        | Возвращает объект указанного класса |

---

## ⚠️ Что нельзя делать в `void` методе

```java
public void doSomething() {
    return 42; // ❌ ошибка компиляции
}
```

→ Метод с `void` не может возвращать значение

✅ Можно просто:

```java
public void doSomething() {
    return; // завершить метод досрочно
}
```

---

## 🎯 Когда использовать `void`

- Метод **выполняет действие**, а не вычисление
- Например:
  - `printResult()`
  - `logError()`
  - `updateState()`
  - `main(String[] args)` — точка входа, не возвращает ничего
