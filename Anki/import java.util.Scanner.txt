import java.util.Scanner;

`import java.util.Scanner;` в Java это инструкция компилятору: **подключить класс `Scanner` из стандартной библиотеки `java.util`**.

---

## 📦 Что делает `import java.util.Scanner;`

- `java` — корневой пакет стандартной библиотеки
- `util` — подмодуль с утилитами (коллекции, таймеры, сканеры и т.д.)
- `Scanner` — класс для **чтения ввода**: с клавиатуры, из файла, строки, потока

→ `import` позволяет использовать `Scanner` без полного имени:

```java
Scanner scanner = new Scanner(System.in);
```

Вместо:

```java
java.util.Scanner scanner = new java.util.Scanner(System.in);
```

---

## 🧠 Как работает `Scanner`

```java
Scanner scanner = new Scanner(System.in);
int number = scanner.nextInt();
```

→ Читает целое число из консоли

---

## 🎯 Где используется `Scanner`

- В интерактивных CLI-программах
- В учебных задачах
- В тестах, где нужно симулировать ввод
- В парсинге строк и файлов

---

## ⚠️ Без `import` — будет ошибка

Если ты не подключишь `Scanner`, компилятор скажет:

```
error: cannot find symbol
Scanner scanner = new Scanner(System.in);
```

→ Потому что он не знает, где искать `Scanner`
